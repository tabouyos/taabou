# FRAX — 対象者だけのFRAXシート自動作成

健診(骨密度検査)の患者一覧から、**FRAXの条件に当てはまる患者だけ**を抽出し、
1人1シートの「FRAX 骨折リスク評価シート」を作成します。

## ファイル

| ファイル | 内容 |
|---|---|
| `make_frax_sheets.py` | 抽出・シート作成スクリプト |
| `FRAX入力_テンプレート.xlsx` | 入力用(「患者一覧」「設定」シート。サンプル患者8名は**架空**) |
| `FRAXシート_サンプル出力.xlsx` | テンプレートから作った出力例(対象2名) |

## 使い方

```
# 1. テンプレートの「患者一覧」に患者を入力(健診システムのCSVをそのまま使ってもよい)
# 2. 実行
python3 FRAX/make_frax_sheets.py FRAX/FRAX入力_テンプレート.xlsx
python3 FRAX/make_frax_sheets.py 健診データ.csv FRAXシート_10月14日.xlsx
```

出力ブックの構成:
- **判定一覧** … 全員を「対象(緑)/要確認(橙)/対象外(灰)」に分け、理由を表示。対象者はFRAXシートへのリンク付き
- **FRAX_<ID>_<氏名>** … 対象者の分だけ作成。FRAXの入力12項目・BMI(自動計算)・結果入力欄・判定・評価者/確認医師欄。A4縦1枚で印刷可

FRAXの確率は公式サイト(https://frax.shef.ac.uk/FRAX/tool.aspx?lang=jp)で計算し、
黄色セルに「主要骨粗鬆症性骨折 10年確率」を入れると判定が自動表示されます。

## 抽出条件(既定値 —「設定」シートで変更可)

骨粗鬆症の予防と治療ガイドライン2015年版の薬物治療開始基準に合わせています。

| 条件 | 結果 |
|---|---|
| 40歳未満・90歳超 | 対象外(FRAXの適用範囲外) |
| 椎体・大腿骨近位部の脆弱性骨折あり | 対象外(骨粗鬆症と診断 → 治療検討へ) |
| その他の脆弱性骨折あり かつ YAM 80%未満 | 対象外(同上) |
| YAM 70%以下 | 対象外(骨粗鬆症域) |
| YAM 80%以上 | 対象外(正常域) |
| **YAM 70%超〜80%未満(骨量減少)** | **対象 → FRAXシート作成** |
| 年齢・性別・YAMが未入力 | 要確認(シートは作らない) |

判定:主要骨折10年確率 **15%以上 → 薬物治療開始を検討**(75歳未満)。75歳以上は15%基準を一律に当てはめず医師の総合判断と表示。

## 入力列

受診日 / 患者ID / 氏名 / 性別 / 生年月日(または年齢) / 身長(cm) / 体重(kg) / 骨密度YAM(%) /
大腿骨頸部骨密度(g/cm2) / 骨密度測定部位 / 椎体・大腿骨近位部の骨折歴 / その他の脆弱性骨折歴 /
両親の大腿骨近位部骨折歴 / 現在の喫煙 / 糖質コルチコイド / 関節リウマチ / 続発性骨粗鬆症 / アルコール1日3単位以上

- 「健診日」「ID」「YAM」「喫煙」など、よくある別名の見出しも自動で読み取ります
- はい/いいえ欄は「あり・はい・○・1」を「はい」、空欄・「なし」を「いいえ」として扱います
- CSVは UTF-8 / Shift_JIS のどちらでも可

## 注意

- 実際の患者データ(出力ファイル含む)はこのリポジトリにコミットしないこと。院内PCで実行・保管する
- 抽出条件・判定は院内の運用(医師の方針)に合わせて「設定」シートで調整する
