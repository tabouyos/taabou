# ティーカップの小さな世界｜SNS自動投稿ワークフロー（引き継ぎ用）

Midjourneyで画像を作って動画にし、BGMをつけて、X・TikTok・Instagramに毎日21時で予約投稿する流れの手順書です。
2026/10/15にCowork＋Claude in Chromeで1回通して実施しました。その内容をClaude Codeで再現するためにまとめています。

## 1. 全体像

```
Midjourney（画像 → 動画化）
   ↓ 動画（無音・5秒）
ブラウザ内でBGMを合成（Web Audio + MediaRecorder → MP4）
   ↓ 横長16:9版（X用）／縦長9:16版（TikTok・インスタ用）
X：x.comの予約投稿
TikTok：TikTok Studioの予約投稿
Instagram：Meta Business Suiteの予約投稿（リール）
```

- 投稿時間：毎日 **21:00（JST）**
- 1サイクル：7本（＋季節の特別編）
- 前提：作業はすべて **ログイン済みのChrome上** で行う（Claude in Chromeが必要）

## 4. Midjourney

### プロンプトの型

```
A tiny [お店や場所] built inside a glass teacup, [中身の描写], miniature people [何をしているか],
a sleepy orange cat [どこにいるか], [光・時間帯・天気],
tilt-shift macro photography, warm cinematic lighting, ultra detailed --ar 16:9
```

- 縦長版：最後を `vertical composition with the teacup centered, ... --ar 9:16` にする
- シリーズのルール：**毎回、眠っているオレンジ色の猫を入れる**（世界観をそろえるため）

### 使ったテーマ（重複しないように）

ラーメン屋、花屋、銭湯（富士山の壁画）、古本屋（雨）、駄菓子屋（昭和）、温泉旅館（紅葉）、神社のお祭り、ハロウィンのパン屋、おばけのお菓子屋、ハロウィンパレード

### 動画化

- 画像にマウスを乗せると出る「Animate」ボタン、または右クリック →「Animate image」→「Auto low motion」
- 1回で4パターンできる。今回は基本的に `0.mp4` を使用
- 詳細画面の中でスクロールすると、表示している画像が切り替わってしまうので注意

### 動画ファイルの場所

```
https://cdn.midjourney.com/video/{job_id}/{0-3}.mp4
```

- `www.midjourney.com` のページ内からは `fetch` で取得できる
- クラウドの作業環境（curl）からは**取得できない**（プロキシで403）
- x.com・tiktok.com のページからも直接は取得できない（CSP/CORSで失敗）

## 5. BGMの合成（ブラウザ内）

同じフォルダの `bgm_engine.js` を使います。

- Web Audio API（OfflineAudioContext）で、テーマごとのオリジナル曲を約5秒で作る
- canvasに動画を描き、`MediaRecorder`（`video/mp4;codecs=avc1.640028,mp4a.40.2`）で音つきMP4として録画し直す
- 縦長版は横幅720pxに拡大して出力（720×1292）
- テーマ：`flower / sento / bookstore / dagashi / onsen / matsuri / halloween / candy / parade`
- **AudioContextはユーザー操作が必要**なので、ページに注入したボタンを実クリックして開始する
- タブは前面に表示したままにする（裏にすると描画が止まる）

## 6. 各SNSへの投稿手順とハマりどころ

### 動画をSNSのページに渡す方法

| 方法 | 使える場所 | 内容 |
|---|---|---|
| **postMessage中継** | X | X側でボタンを押して `window.open` でMidjourneyタブを開く → Midjourney側で `fetch` → `window.opener.postMessage({mjname, blob})` → X側で `File` に変換 |
| **自前のファイル選択ボタン** | TikTok、インスタ、Business Suite | ページに `<input type=file multiple>` 付きのボタンを注入し、**本人に1回だけ9本選んでもらう** → `window.__picked` に保存 |
| ファイル入力への注入 | 全部 | `DataTransfer` で `input.files` を差し替えて `change` イベントを発火 |

- TikTokはCOOPのせいで `window.opener` が切れるので、postMessage中継は**使えない**
- ネイティブのファイル選択ダイアログはClaudeから操作できない
- SPA内の移動ならメモリ上のファイルは残る。ページを再読み込みすると消える

### X（x.com）

1. 投稿画面で動画を注入 → 本文を入力
2. 予約アイコン（`aria-label="ポストを予約"`）→ 日付と時刻のselectを設定 →「確認する」→「予約設定」
3. 予約済みの投稿の差し替え：「下書き」→「予約済み」→ 投稿を開く → メディアを削除して注入し直し →「予約設定」（重複はしない）
4. ハッシュタグ：`#AIart #Midjourney #ミニチュア #ティーカップの小さな世界`（ハロウィン回は `#ハロウィン` を追加）
5. 「AIart」は画面上だと「Alart」に見えるが、問題なし

### TikTok（TikTok Studio）

1. `tiktok.com/tiktokstudio/upload`、ファイル入力は `input[accept="video/*"]`（1本ずつ）
2. 説明文：`ctrl+a → Delete → 入力` の順で**キーボードで打つ**。`execCommand('insertText')` を使うと文字が重複する
3. 「投稿予約する」を選び、日付はカレンダーを実クリック、時刻は `.tiktok-timepicker-option-list` の項目を実クリック（21と00）
4. 「さらに表示」→「AI生成コンテンツ」をON →「オンにする」
5. 著作権と内容のチェックが終わるのを待ってから「投稿予約する」を押す。終わる前に押すと「今すぐ投稿」の確認が出る
6. ハッシュタグ：`#ティーカップの小さな世界 #ミニチュア #AIart #癒し #猫`

### Instagram（Meta Business Suite）

- **instagram.comでは予約もアーカイブもできない**（アーカイブはスマホアプリのみ）
- `business.facebook.com` →「リール動画を作成」
1. 「動画を追加」は、`HTMLInputElement.prototype.click` を差し替えて**ダイアログを開かずにinputを捕まえる** → 注入
2. キャプションを入力 →「次へ」→「次へ」→「日時を指定」
3. 日付：`input[placeholder="yyyy/mm/dd"]` に `2026/10/16` と入力してEnter。時刻：`input[aria-label="時間"]`、`input[aria-label="分"]`
4. 最後の「日時を指定」ボタンで予約。確認は「コンテンツ」→「日時指定済み」（表示に少し時間がかかる）
5. ハッシュタグ：TikTokと同じもの＋`#猫好きさんと繋がりたい`

## 8. 決めたこと・注意点

- 予約投稿はX・TikTok・インスタの**それぞれ公式の機能**を使う（外部の自動投稿サービスは使わない）
- Ootto（Composio-IG経由）は連携を解除済み。インスタの二重投稿に注意
- アカウントの作成・ログイン・ファイルの選択は本人が行う
- 投稿・予約の確定は、本人の確認を取ってから押す
- インスタの過去11件（猫の雑学）はそのまま。気になったらアプリでアーカイブする
