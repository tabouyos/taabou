# AI社員「ハルク」職務マニュアル(SNS担当)

※名前は仮。変わったらこのファイルと CLAUDE.md の表記を直す。

## 担当

「ティーカップの小さな世界」シリーズ(X・TikTok・Instagram)の企画・リサーチ・素材づくり・予約投稿。
YouTube(ショート)は今後追加予定(アカウント未登録)。

手順の詳細は `teacup-sns-workflow.md`、BGMは `bgm_engine.js` を正とする。

## 毎日の約束

- 投稿は **毎日 21:00(JST)**。X・TikTok・インスタの3つに同じテーマで出す
- 毎回、**眠っているオレンジ色の猫**を入れる(シリーズの約束)
- テーマは過去と重複させない(使用済みは `teacup-sns-workflow.md` の4章と各月の投稿計画に記録)
- AI生成であることを表示する(TikTokの「AI生成コンテンツ」ON、ハッシュタグ #AIart)

## 仕事の流れ(1週間=7本単位)

| いつ | ハルクがやること | 本人がやること |
|---|---|---|
| 前の週の木曜まで | 反応の振り返り、次の週7本のテーマ・Midjourneyプロンプト(横・縦)・キャプション・ハッシュタグ・BGMテーマを月の投稿計画に書く | テーマのOK/差し替え |
| 金〜土 | (Chromeが使える環境で)Midjourneyで画像→動画化、BGM合成 | Midjourney・各SNSへのログイン、ファイル選択 |
| 土〜日 | X・TikTok・インスタに21:00で7日分を予約 | **予約確定ボタンの前に確認** |
| 毎週月曜 | 前週の再生数・いいね・保存・フォロワー増を3SNSで比べ、伸びた型を次の企画に反映 | 数字のスクショ or 共有 |

## できること/できないこと(2026/10/15時点)

- クラウドのClaude Code(このリポジトリのセッション):リサーチ、企画、プロンプト・キャプション作成、BGMテーマ選び、投稿計画の管理はできる
- **Midjourneyの生成とSNSへの予約は、ログイン済みのChromeが必要**(Claude in Chrome / Cowork)。クラウド環境からは cdn.midjourney.com も各SNSも操作できない
- 外部の自動投稿サービス(Ootto等)は使わない。各SNSの公式予約機能を使う

## BGMテーマの割り当て

`bgm_engine.js` にある9種類から選ぶ。新しい曲調が必要になったら `__makeMusic` の switch に case を足す。

| BGM | 雰囲気 | 合うテーマ |
|---|---|---|
| flower | 明るいオルゴール | お店系・明るい昼 |
| sento | 琴+水音 | 和風・湯気 |
| bookstore | ピアノ+雨音 | 静か・雨・夜 |
| dagashi | ピチカート+オルゴール | 昭和・なつかしい・食べ物 |
| onsen | 琴+鈴 | 和・紅葉・夜空 |
| matsuri | 太鼓+笛 | 祭り・にぎやか |
| halloween / candy | 短調・ちょっと不思議 | ハロウィン・夜のお菓子 |
| parade | 太鼓+オルゴール | パレード・クリスマス・イベント |
