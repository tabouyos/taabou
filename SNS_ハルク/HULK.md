## 担当

YouTube(ショート)は、インスタのプロフィールにリンクしているチャンネルを使う(本人が設定済み・予約投稿も登録済み、10/16確認。アドレスは未記録)。縦長9:16版を流用し、YouTube Studioの予約公開で同じ21:00に出す(「改変されたコンテンツ/合成コンテンツ」の開示をONにする)。

Substack(https://substack.com/@taabou)は、**毎週日曜21:00に記事「ティーカップ通信」**(その週の7本のまとめ・猫の場所・つくりかた・プロンプト・来週のリクエスト募集)を予約公開する。**ノートで毎日21:00に「小さなカップ」を投稿する(必須、本人希望 10/16)**。動画(縦長9:16)を付けられればそのまま、付けられなければ1コマ目の画像+ひと言。文面は `substack/ノート_YYYY-MM.md`。下書きは `substack/` に置く(第1号:`substack/vol01_2026-10-25_下書き.md`、10/25公開予定)。

手順の詳細は `teacup-sns-workflow.md`、BGMは `bgm_engine.js` を正とする。

## 毎日の約束

- 投稿は **毎日 21:00(JST)**。X・TikTok・インスタ・YouTubeショート・Substackノートに同じテーマで出す
- 見た目の見本:`reference/猫動画の見本_縦.webp`(白いティーカップ+ソーサー、木のテーブル、湯気、カップの中にミニチュアの家と木、手前のクッションで眠る茶トラの子猫が大きく主役)
  - 見本の動画(10/16本人提供):**Kling**で作成、5秒、縦1080×1920、24fps、**音なし**。動きは「ゆっくりカメラが寄る+湯気がゆらぐ」(検討レポートの施策D=カメラが寄る動き と同じ)。5秒の流れは `reference/猫動画の見本_5秒の流れ.jpg`
- 毎回、**眠っているオレンジ色の猫**を入れる(シリーズの約束)
- テーマは過去と重複させない(使用済みは `teacup-sns-workflow.md` の4章と各月の投稿計画に記録)
- AI生成であることを表示する(TikTokの「AI生成コンテンツ」ON、ハッシュタグ #AIart)

## できること/できないこと(2026/10/15時点)

- クラウドのClaude Code(このリポジトリのセッション):リサーチ、企画、プロンプト・キャプション作成、BGMテーマ選び、投稿計画の管理はできる
- **Midjourneyの生成とSNSへの予約は、ログイン済みのChromeが必要**(Claude in Chrome / Cowork)。クラウド環境からは cdn.midjourney.com も各SNSも操作できない
- 外部の自動投稿サービス(Ootto等)は使わない。各SNSの公式予約機能を使う

## 動画づくりの分担(10/16決定)

- 画像:Midjourney(Basic)。動画:**Kling(fal.ai経由)**。**縦長9:16を1日1本だけ作り、全SNS共通で使う**(Xも縦動画を表示できる。横長版は作らない)
- BGM:**クラウドのハルクが付けられる**。動画(音なし)をこのチャットにアップロード → `render_bgm.js` で `bgm_engine.js` の曲を書き出し → ffmpegで合成・音量をSNS向け(-16 LUFS)にそろえる
  ```
  node SNS_ハルク/render_bgm.js SNS_ハルク/bgm_engine.js <テーマ> <秒数> out.wav
  ffmpeg -i 動画.mp4 -i out.wav -map 0:v -map 1:a -c:v copy -af "loudnorm=I=-16:TP=-1.5:LRA=11" -c:a aac -b:a 192k -shortest 出力.mp4
  ```
- できあがった動画は `output/` に置く(mp4はgitに入れない)
- Substackの毎日ノートも同じテーマ・同じ動画(本人確認 10/16)

## BGMテーマの割り当て

| sento | 琴+水音 | 和風・湯気 |
| bookstore | ピアノ+雨音 | 静か・雨・夜 |
| dagashi | ピチカート+オルゴール | 昭和・なつかしい・食べ物 |
| onsen | 琴+鈴 | 和・紅葉・夜空 |
| matsuri | 太鼓+笛 | 祭り・にぎやか |
| halloween / candy | 短調・ちょっと不思議 | ハロウィン・夜のお菓子 |
| parade | 太鼓+オルゴール | パレード・クリスマス・イベント |
| lullaby | やさしいオルゴールの子守唄 | 眠る子猫が主役・家や村・夜(10/16追加) |
