# エステ予約帳

勤務シフトに合わせてエステの予約を管理する1ページのWebアプリです（`index.html`）。

- **勤務シフト**：職場チャットの勤務表を貼り付けると「10/1 日勤」「1日 夜勤」「3(土) 休み」「5 明」などを読み取ってカレンダーに反映。タップで個別修正も可能。
- **受付ルール**：日勤の日は 18:00 から、休みの日は 8:00 から受付（設定で変更可）。夜勤・明け・遅番は初期設定では受付なし。予約は1件90分。
- **予約を入れない日時**：終日または時間帯を指定してNGにでき、空き枠から除外されます。
- **メニュー**：エステ・美容点滴・整体から2つまで選択（料金なし。名前と選べる数は設定で変更可）。
- **当日予約は個人LINE**：お客様向け画面では当日分は表示せず、LINE ID（rx445h）と友だち追加URLを案内。オーナーはLINEで受けた当日予約を「予約」タブから登録。
- **予約**：1件の時間＋片付け時間で重複をチェックし、空いている開始時間だけを選べます。
- **お客様向け空き**：勤務は月末に翌月分が出るため、勤務が入っている最後の月の末日まで（最長で来月末）の空き枠を表示し、LINE・SNS用の案内文をコピーできます。

ブラウザで `index.html` を開くだけで動きます（データはそのブラウザに保存）。claude.ai のArtifactとして開いた場合はクラウドに保存され、スマホとPCで共有されます。
