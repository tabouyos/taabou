# エステ予約帳

勤務シフトに合わせてエステの予約を管理する1ページのWebアプリです（`index.html`）。

- **勤務シフト**：「日勤」などの勤務を選んでから日付をタップして入力（スマホ向け）。職場チャットの勤務表を貼り付けると「10/1 日勤」「1日 夜勤」「3(土) 休み」「5 明」などを読み取ってカレンダーに反映。タップで個別修正も可能。
- **受付ルール**：予約のあとは2時間（施術90分＋空け時間30分）次の予約を入れない。日勤の日は 18:00 から、休みの日は 8:00 から受付（設定で変更可）。夜勤・明け・遅番は初期設定では受付なし。予約は1件90分。
- **予約を入れない日時**：終日または時間帯を指定してNGにでき、空き枠から除外されます。
- **メニュー**：エステ・美容点滴・整体から2つまで選択（料金なし。名前と選べる数は設定で変更可）。
- **当日予約は個人LINE**：お客様向け画面では当日分は表示せず、LINE ID（rx445h）と友だち追加URLを案内。オーナーはLINEで受けた当日予約を「予約」タブから登録。
- **予約**：1件の時間＋片付け時間で重複をチェックし、空いている開始時間だけを選べます。
- **お客様向け空き**：勤務は月末に翌月分が出るため、勤務が入っている最後の月の末日まで（最長で来月末）の空き枠を表示し、LINE・SNS用の案内文をコピーできます。

ブラウザで `index.html` を開くだけで動きます（データはそのブラウザに保存）。claude.ai のArtifactとして開いた場合はクラウドに保存され、スマホとPCで共有されます。
- **お客様向けかんたん表示**：年配の方向けに、大きな文字で「ご予約できる日」と「午後6時〜7時半のあいだ」のような時間帯だけを表示。予約のしかた（LINEで名前・日時・メニューを送る）も案内します。共有された閲覧専用の人にはこの画面だけが表示されます。
- **時刻を押して申し込み**：お客様用画面で時刻を押すと申し込みフォームが開き、名前・メニュー・ご要望を入れて「LINEで送る」を押すと、その内容でLINEが開きます（受付はLINEのみ）。
- **お客様用リンク**：「お客様向け空き」タブの「お客様用リンクを更新」を押すと、その時点の空き状況（日付と開始時刻・メニュー名・LINE IDのみ。お客様の名前などは含まない）をページ自身に書き込んで公開し直します。共有メニューで公開リンクにすると、お客様はログインなしでその空き状況だけを見られます。オーナーが開くと自動で管理画面に切り替わります。

> メモ：ページの空き状況はページのHTMLの中（`#snap`）に入っています。Claude側からこのファイルを公開し直すと空き状況が空に戻るので、そのあとはオーナーが「お客様用リンクを更新」を押し直してください。
- **申し込みの貼り付け**：LINEで届いた申し込み文（「日時：10月5日（月） 18:00〜」「お名前：」「メニュー：」「ご要望：」）を予約タブに貼り付けて「読み取って入力」を押すと、予約フォームが埋まります。すでに埋まっている時間なら知らせます。
- **お客様用リンクの自動更新**：予約・勤務・NG日時・設定を保存すると、数秒後に自動でお客様用リンクの空き状況も更新されます（入力中は待ちます）。
